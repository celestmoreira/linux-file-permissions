# **Linux File Permissions Project**

This project was completed as part of the **Google Cybersecurity Certificate**. The goal was to practice reviewing and updating Linux file and directory permissions using commands like `ls -l`, `ls -la`, and `chmod`.

All work for this project, including explanations and screenshots, is documented in [project.md](project.md).
The [screenshots](screenshots/) folder contains the terminal output used throughout the activity.

This project helped reinforce the basics of:

- Reading Linux permission strings
- Understanding user, group, and other
- Modifying permissions with chmod
- Working with hidden files and directories
- Applying least-privilege principles in a Linux environment
